# Chess Room
同じ合言葉で2人がリアルタイム対戦するチェスゲームです。

## 起動と検証
Node.js 22以上を推奨します。

```sh
npm ci
npm start
npm test
```

http://localhost:3000 を2つのブラウザで開き、同じ4〜64文字の合言葉を入力します。最初の人が白、次の人が黒です。駒と移動先をタップして操作します。合法手、昇格、チェックメイト、引き分けはサーバーでも判定します。再戦は2人の承認が必要です。

## Render
このリポジトリの `render.yaml` で無料のNode Web Serviceを作成できます。手動設定は Build Command `npm ci`、Start Command `npm start`、Health Check `/healthz` です。Static SiteではなくWeb Serviceを使用してください。環境変数PORTで指定されたポートの0.0.0.0で待ち受けます。

## 制約
- 1インスタンス構成です。対局データはメモリ内にあり、再起動や再デプロイで消えます。
- 切断後は再接続してから同じ合言葉で再入室してください。空いた席は合言葉を知る人が利用できます。全員が退室した部屋は削除されます。
- 合言葉はNFKCで正規化します。推測されにくい専用の文字列を使用してください。
- ライブラリと画面は同じサーバーから配信し、外部CDNには依存しません。

## オンラインの検証
公開後は `TEST_URL=https://実際のサービスURL npm test` で独立したWebSocketクライアントから対戦を検証できます。テスト用の一意な合言葉を作成し、接続を終了すると削除します。
