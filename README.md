# Chess Room
合言葉で2人がリアルタイム対戦できるチェスゲームです。

## ローカルで起動
Node.js 18以上が必要です。

```bash
npm install
npm start
```

http://localhost:3000 を開きます。

## 公開
Render、RailwayなどのNode.js/WebSocket対応ホスティングにこのフォルダを配置し、Build Commandを `npm install`、Start Commandを `npm start` に設定します。公開URLを友達に共有し、同じ合言葉を入力します。無料プランの有無やスリープ仕様は各サービスで確認してください。

## 注意
- ルーム情報はメモリ上だけに保存されます。再起動すると消えます。
- 同時入室は2名まで。切断した席には別の人が入室できます。
- サーバーは1インスタンス構成です。
- 合言葉は4文字以上。推測されにくい文字列を使用してください。
- 対局中の再接続・観戦・レーティングには未対応です。
- クライアントの chess.js はCDNから読み込みます。インターネット接続が必要です。
